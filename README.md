# Okibe Roy Samson — Portfolio

A responsive personal portfolio built with React, TypeScript, Vite and CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Add a personal portrait at `public/images/profile.jpg` to replace the initials artwork in the About section. Contact destinations are intentionally left as placeholders until real links are provided.
